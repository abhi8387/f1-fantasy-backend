\textbf{F1 Fantasy Backend} \hfill \textit{Node.js, Express, MySQL, Sequelize, Redis, JWT, Docker} \hfill \href{https://github.com/abhi8387/f1-fantasy-backend}{GitHub}
\begin{itemize}
    \item Built a feature-based fantasy sports backend (auth, leagues, races/drivers, lineups, scoring, leaderboard) on MySQL + Sequelize, with JWT access/refresh tokens (Redis-backed, revocable), bcrypt hashing, and a Redis-backed rate limiter on auth endpoints.
    \item Synced live race and driver data from the OpenF1 API, including each race weekend's real Practice 1 session time to gate fantasy-lineup submissions until practice actually starts, rather than an arbitrary cutoff.
    \item Designed a 5-driver squad system with talent-tier driver pricing (team competitiveness plus a star-driver premium) and a fixed budget, enforced server-side, so squad-building requires real trade-offs; a fixed points-by-finishing-position scoring table locks a race once results are entered.
    \item Built a per-league leaderboard computed on read from race results and submitted lineups (captain picks doubled), and a plain HTML/CSS/vanilla-JS multi-page frontend served directly by the same Express app.
    \item Containerized the full stack with Docker Compose (MySQL, Redis, backend, healthchecks) for a reproducible local environment.
\end{itemize}
